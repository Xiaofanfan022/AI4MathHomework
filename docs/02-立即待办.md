## ① 吊销泄漏的 API Key（最高优先级）

这两个 Key 曾以明文写在 `FirstAgentTest.py` 里，已经随文件存在于磁盘上。虽然还没推 GitHub，但**任何形式的分享、备份、截图都可能造成泄漏**。稳妥做法是直接吊销重建。

**aihubmix Key**（`sk-hn0U...`）
1. 登录 <https://aihubmix.com> → 个人中心 / API Keys
2. 找到对应 Key → 删除 / 禁用
3. 新建一个，复制新 Key

**Tavily Key**（`tvly-48ex...`）
1. 登录 <https://app.tavily.com> → API Keys
2. 删除旧 Key，新建一个

> 这两个平台都有免费额度，作业用量完全够。

3. `git remote add origin ...` → `git push -u origin main`
