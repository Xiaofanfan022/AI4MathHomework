# 01_cover

（8 秒）

各位老师、同学好，我是……。这次中期汇报的题目是《用智能体自动猜想图的不变量不等式》。

我想先讲清楚一件事：我做的这个智能体不会写证明。它做的事是——在一堆图的不变量之间，自己找出一些可能永远成立的不等式，然后自己想办法把它们推翻。

# 02_problem

（45 秒）

先说问题。

图有很多可以数的量：顶点数 n、边数 m、最大度 Δ、最小度 δ、独立数 α、团数 ω、色数 χ、匹配数 ν，还有邻接矩阵的谱半径 ρ。这九个量之间藏着大量不等式，有些一行就能证，比如 χ + α ≤ n + 1；但有些极难，比如 Reed 猜想，1998 年提出，说 χ ≤ ⌈(ω + Δ + 1)/2⌉，到现在还没解决。

我这个项目的目标形式是：九个量分成左右两边，各带系数，右边再加一个常数，问能不能对所有图都成立。

注意这类命题的特点——陈述极其初等，初中生都能看懂；但证明可以难到没人做出来。这正好适合让机器来提。

# 03_hard

（28 秒）

但真正的问题不是生成，是筛选。

三个原因。第一，产出远超人工：八十年代的 Graffiti 系统提出过上千条图论猜想，最后是靠人一条一条读、一条一条挑。第二，小样本不算数：几万张图上零违反，换到更大的图就可能失效——我自己就实测过，χ ≤ ω + 1 在八阶以内 13598 张图上全部成立，到 11 阶就找到了反例。第三，同时检验上百条，总有一条碰巧通过，这是纯粹的概率问题。

所以这不是生成问题，是筛选问题。而筛选是可以被量化的。

# 04_loop

（36 秒）

我的做法是把筛选做成一条闭环。

四步。第一步，模型提出候选形式：用哪几个不变量、什么方向、谁在左边。第二步，解线性规划定系数——这一步不给模型，因为系数是解出来的，不是猜出来的。第三步，主动搜反例：随机图、结构化族、局部修改三种策略。第四步，统计筛选：置换检验算 p 值，再做多重检验校正，最后在没参与拟合的测试集上复核。

每一步都写进 JSONL 轨迹，失败的原因回灌给下一轮。

右边这两列是我划的界线：模型只负责提形式、解释失败、判新颖性、选策略这四件需要语义理解的事；解方程、生成图、算 p 值、记日志全部交给确定性代码。这样每一步都可复现、可审计。

# 05_data

（26 秒）

地基是数据。

27810 张图。八阶以内完全枚举——各阶图的个数是 1、2、4、11、34、156、1044、12346，和 OEIS 上的序列完全一致，说明枚举没漏。九到十二阶采样，再补一批结构化族。

九个不变量全部精确计算。色数、独立数、团数都是 NP-难的，我没有用上界代替，而是写了分支定界精确求解。

右边这个 0 是四条已知结论在全量数据上的违反数。零违反，说明计算管道本身是对的。

# 06_baseline

（34 秒）

在接模型之前，我先验证这条链路自己能不能跑通。

左边是五条已知结论，全部由线性规划自动定出系数，全量数据复验零违反。这一步改过三次目标函数才成功——如果只最小化常数项，它会偏好 χ ≤ n 这种几乎没信息量的弱形式；改成最小化平均松弛量之后，才把 χ ≤ n − α + 1 这种紧的形式找出来。

右边是三种反例搜索策略的对比。横轴是找到反例时已经评估了多少张图。结构化族找到 χ ≤ ω + 1 的反例，中位数 50 张图，随机图 8 次全部落空；局部修改在另两条上最快，中位数只要 1 到 3 张。

但请注意最后一行小字：结构化族的候选池只有 122 张图，用完之后补的都是随机图。这是下一页负面结论的伏笔。

# 07_funnel

（38 秒）

接上模型，跑了五轮。

26 次调用，提出 40 条候选，被反例推翻 5 条，最后活下来 3 条。

三条是：α ≤ n − ν，取等率 31.6%；α ≤ n − ω + 1，1.7%；χ ≤ ρ + 1，0.5%。三条的 p 值都是 0.005——这是 200 次置换能达到的下限，说明零分布里从来没有出现过这么紧的形式。

但我必须说清楚：这三条事后核对，全都是已知结论。第三条就是 Wilf 1967 年的定理。

所以这一页证明的不是"智能体发现了新定理"，而是"这条链路能独立地把已知定理重新发现一遍"。这是正确性验证，不是成果宣称。

# 08_negative

（34 秒）

接下来是我认为这次最有价值的一个发现，而且是个负面结论。

我构造了 30 条已知为假的命题，每条在真实数据上至多 5 张反例、反例阶数都在 9 以上，然后看智能体能不能找出来。

结果：预算从 50 张图扩大到 3000 张图，扩大六十倍，结构化族的检出率只从 0.27 升到 0.30。更极端的是，只有 1 张反例的那 18 条命题，检出率是 0.02。

结论是：瓶颈不在预算，在支撑集。结构化池只有 122 张图，用完了就是在随机图里瞎撞，而随机图几乎不可能撞到稀疏的反例。

这个结论对整个领域都成立——所有靠"没找到反例"来支持猜想的方法，在难例上这个证据几乎是零信息。

# 09_ablation

（26 秒）

最后讲一个差点让我得出错误结论的消融。

我做了随机抽样和模型提议的对照。第一轮跑完，随机组四项指标全胜，我差点就在报告里写"模型没有用"。

但翻看保留清单才发现问题：随机组抽到了大量 ω ≤ χ、δ ≤ Δ 这种定义直接成立的恒真式，等于白送分。不是模型差，是我的检查器漏了一条基本事实。

补到 35 条基本事实、用同一个剔除规则重跑，结论翻转了：后两级指标模型组反超。

但保留意见我也写在这里——三组种子只胜两次，样本不够，报告不作"模型优于随机"的声称。两次翻转的真正价值，是暴露了检查器的漏洞。

# 10_next

（25 秒）

接下来可以往哪走。五条互不排斥的方向。

第一，长期自主运行：断点续跑、去重账本、预算上限、自动日报这四件工程我已经写好了。第二，扩大表达力：预测子从 2 个加到 3 个，形式空间从 2304 涨到 59472。第三，改进反例搜索：用 bandit 分配预算、扩充结构化族、上 SAT 精确搜索。第四，换问题域：Heilbronn 三角形、其他不变量族、组合设计。第五，让模型参与证明：接 Lean，把猜想推到可证。

但先说清楚瓶颈——不是时间。形式空间只有 2304 条，穷举之后只有 34 条能过全部关卡，智能体五轮就已经提了 25 条互异形式，照现在的设定几个小时就饱和了。所以长期运行必须同时扩张形式空间，否则跑一周的后半段全是重复。

最后一句总结：这个项目的价值不在结论。它把"信不信一条猜想"从一句直觉，变成了一个有 p 值、有反例预算、有消融对照的可测量过程。
