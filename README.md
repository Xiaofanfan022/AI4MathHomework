# 用智能体自动猜想图的不变量不等式

课程「人工智能与数学」的作业。核心工作不是解决某个具体的数学猜想，而是
**开发一个智能体，让它自己提出图论中的不等式猜想，并检验这些猜想**，然后
把智能体的运行与迭代过程完整记录下来。

## 研究的问题

图的不变量之间存在大量不等式，例如

$$\chi(G) + \alpha(G) \le n + 1$$

（色数加独立数不超过顶点数加一）。这类不等式陈述简单、验证便宜，但**发现
不显然**——上面这条只需一行证明，可它并不是一眼能看出来的。

Reed 在 1998 年提出 $\chi \le \lceil (\omega + \Delta + 1)/2 \rceil$，至今
未解决；它的两个端点分别退化为 Brooks 定理与平凡界。这说明"陈述初等"与
"证明困难"可以同时成立。

**真正的困难不是想不出，而是想得太多。** 九个不变量两两组合就能产生几千条
候选形式，人工无法逐条核对；而小规模数据上成立的候选，未必能推广。

## 智能体怎么工作

四步闭环，**数值计算全部交给程序，模型只做四件判断**：

```
提出候选  →  求解系数  →  搜索反例  →  统计筛选
   ↑                                      │
   └──────── 失败教训回传提示词 ←──────────┘
```

1. **提出候选**（模型）：决定用哪些不变量、什么符号、哪个方向。
2. **求解系数**（程序）：线性规划在数据上定系数，模型不给数值。
3. **搜索反例**（模型选策略，程序执行）：随机图 / 结构化族 / 局部修改。
4. **统计筛选**（程序）：置换检验给 p 值，BH 控制错误发现率。

模型负责的四件事：提出形式、解释失败、选择搜索策略、判断是否已知。
**不让模型做的**：给系数、算不变量、判定成立与否。

## 主要结果

数据：**27810 张图**（$n \le 8$ 完全枚举 13598 张，$n = 9..12$ 采样 14212 张），
九个不变量全部精确计算，四项已知结论零违反。

- 智能体五轮共提出 40 条形式，推翻 5 条，保留 3 条，均在测试集上成立。
- 穷举上界：完整形式空间 2304 条中，通过全部关卡的只有 34 条。智能体保留的
  三条在其中排名第 1、7、12。
- **消融实验的结论随检查器改进而翻转**：第一次随机组全面胜出，补上恒真式
  识别后模型组反超。因此报告不作"模型优于随机"的声称。
- 注入难例显示反例搜索在只有 1–4 张反例的命题上检出率仅 0.02–0.34，且
  **加大预算无效**——瓶颈在搜索分布的支撑集，不在算力。

## 快速开始

```powershell
# 前几步完全离线，不需要 API Key
python -m crp_agent.build_dataset        # 构造数据集（约 1 分钟）
python -m crp_agent.validate_dataset     # 用已知结论校验
python -m crp_agent.viz.stage1_plots     # 阶段一图表
python -m crp_agent.run_baseline         # 阶段二基线（不调用模型）

# 以下需要 API Key，见 .env.example
python -m crp_agent.agent --rounds 5     # 智能体主循环
python -m crp_agent.ablation             # 消融实验
```

完整步骤见 [`crp_agent/README.md`](crp_agent/README.md)。
